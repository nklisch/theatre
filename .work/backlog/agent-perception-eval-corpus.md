# Committed benchmark corpus for agent perception

Parked during visual-storyboards ideation (2026-07-25), inspired by
krometrail's temporal-evaluation crate (feature-gated, non-runtime;
SHA256-pinned fixtures; case families like flicker/movement-reversal with
scoring rubrics). A theatre equivalent would regression-test "can an agent
correctly diagnose a physics-jitter/rendering bug from storyboard + spatial
data." A future investment once visual artifacts exist and real agent
sessions reveal misdiagnosis patterns; not needed to ship v1.
