# Clarify Stage's default launch state

The canonical Stage skill, both bundled client copies, the getting-started guide,
and the journeys guide now state that ordinary launches keep Stage present while
observation and recording are off by default. This removes wording that could be
read as excluding Stage itself from the launch.

The repository's bundled-skill synchronization check passed, the old ambiguous
phrases are absent from the five files, and the focused documentation review found
no conflicting behavior or scope expansion.
