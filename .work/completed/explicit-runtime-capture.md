# Explicit, human-ready runtime capture

Ordinary launches leave Stage observation and capture off. Independent startup
and play options support Minimal, Light, Standard and Heavy presets, explicit
project readiness, unattended human waiting, immutable continued segments,
bounded metrics and metadata providers, scoped spatial/image channels, and
deliberate Keep/Discard or automatic retention policies. Installation requires
project consent; portable shared settings and approved private overrides remain
separate. Consumer-specific integrations are outside Theatre.

Verified with Windows Godot 4.7.1: workspace build, formatting, strict Clippy,
ordinary tests and every ignored engine suite (with corrected integration suites
rerun), including native editor lifecycle, live rendering, wire operations and
human controls. Public schema/site generation and canonical/client skill checks
pass. The inline delivery review corrected capture clock consistency, retention,
legacy channel reporting and setup preservation; no independent review is claimed.

The self-contained release fixture measured physics-monitor medians of roughly
0.09 ms off, 0.39 Minimal and 5.92 Heavy. These are local comparative measurements,
not total observer-cost or production guarantees. Linux/macOS engine execution
was not available. No consuming-project changes or release are part of this
delivery.
