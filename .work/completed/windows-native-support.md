# Complete native Windows support

Completed portable CLI installation and configuration, safe Stage first-run
initialization, and reliable Director process ownership on Windows while
preserving Unix behavior. Documentation now presents Windows instructions as
additive platform guidance rather than replacing POSIX instructions.

Formatting, strict Clippy, and the full workspace suite passed. Native Windows
verification also covered source installation, initialization, missing Stage
extension handling, Director and wire journeys, the Director-to-Stage MCP
journey, and descendant-process cleanup.
