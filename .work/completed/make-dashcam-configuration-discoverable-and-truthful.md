# Make dashcam settings discoverable and their application truthful

A shared typed recorder configuration defines flat patch keys, defaults, presets and validation. Invalid patches do not partially apply, and effective settings and buffered coverage are observable. Explicit project intent no longer duplicates spatial-session defaults; rejected project settings are reported without disabling unrelated tools. Engine tests cover numeric and Godot-dependent rejection.
